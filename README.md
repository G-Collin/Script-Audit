# Script-Audit
Exercice sur une rapide audit, dans le cadre d'une formation Linux.

## Objectif :
### Faire une script pour une audit avec les éléments suivants :
- Hostname (Nom Machine) - Uname (Version Noyau) - Date (Date) - Whoami (User) Ps (Processus) - Wc (Compter les lignes Processus) - Free (Ram) - Df (Disk).
